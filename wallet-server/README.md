# Azkar Wallet server

Signs the "Today's prayers" Apple Wallet card. The app writes the card's content and this server signs it with the Pass Type ID certificate, since that private key must never be inside the app. It keeps nothing.

The app replaces the card whenever you log a prayer and each new day, so there are no push notifications to set up.

- `src/index.js`: the one endpoint, `POST /v1/pass`.
- `src/sign.js`: builds and signs the `.pkpass` file.
- `src/images.js`: the card's icon and logo, generated by `scripts/make-images.sh`.
- `npm test`: signs a sample card with throwaway certificates and checks the result.

## Setting it up (once)

You need: the paid Apple Developer account, a free Cloudflare account, and the Terminal. Run every command from this folder (`wallet-server`).

### 1. Create the Pass Type ID

1. Open developer.apple.com › Account › Certificates, IDs & Profiles › Identifiers › **+**.
2. Choose **Pass Type IDs**, then Continue.
3. Fill in:
   - **Description:** `Azkar Today`
   - **Identifier:** `pass.io.github.ahmedwalid4499.azkar`
4. Register it.

### 2. Make its certificate

1. On the Mac, open **Keychain Access** › menu Keychain Access › Certificate Assistant › **Request a Certificate From a Certificate Authority**.
2. Enter your email, choose **Saved to disk**, and save the `.certSigningRequest` file.
3. Back at developer.apple.com, open the Pass Type ID you just made › **Create Certificate**.
4. Upload that file and download `pass.cer`.
5. Double-click `pass.cer` so it goes into Keychain Access.
6. In Keychain Access › **My Certificates**, find "Pass Type ID: pass.io.github.ahmedwalid4499.azkar". Right-click it › **Export**, save as `pass.p12` in this folder, and choose a password.
7. Turn it into the two files the server reads. Each command asks for the password you just chose:

```bash
openssl pkcs12 -legacy -in pass.p12 -clcerts -nokeys -out pass-cert.pem
```

```bash
openssl pkcs12 -legacy -in pass.p12 -nocerts -nodes -out pass-key.pem
```

### 3. Get Apple's intermediate certificate (WWDR G4)

Download **Worldwide Developer Relations - G4** from apple.com/certificateauthority (the file is `AppleWWDRCAG4.cer`) into this folder, then:

```bash
openssl x509 -inform DER -in AppleWWDRCAG4.cer -out wwdr.pem
```

### 4. Put the server on Cloudflare

Sign in to Cloudflare (a browser window opens):

```bash
npx wrangler@4 login
```

Deploy:

```bash
npx wrangler@4 deploy
```

Store the secrets. Each command reads a file and sends it to Cloudflare encrypted:

```bash
npx wrangler@4 secret put PASS_CERTIFICATE < pass-cert.pem
```

```bash
npx wrangler@4 secret put PASS_KEY < pass-key.pem
```

```bash
npx wrangler@4 secret put WWDR_CERTIFICATE < wwdr.pem
```

```bash
npx wrangler@4 secret put APP_KEY < .app-key
```

Then your team ID, the 10 characters shown at developer.apple.com › Account › Membership details (paste it when asked):

```bash
npx wrangler@4 secret put TEAM_ID
```

The deploy prints the server's address, like `https://azkar-wallet.<your-name>.workers.dev`. Send that address to Claude: it goes into the app's `AzkarWalletServer`, and the next build shows "Add to Apple Wallet" in Settings.

### 5. Clean up

Once the secrets are stored, the `.pem`, `.p12` and `.cer` files can go. Git already ignores them, and `.app-key` too.

## Notes

- `.app-key` is the small key the app sends with each request, so strangers can't use the server. It reaches the app at build time (`AZKAR_WALLET_KEY`) and is never committed.
- The Pass Type ID certificate is valid for about a year. Renew it at developer.apple.com and run step 2 and `secret put PASS_CERTIFICATE` / `PASS_KEY` again.
